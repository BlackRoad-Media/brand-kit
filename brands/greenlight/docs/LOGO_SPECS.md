# GreenLight Logo Specifications

## Logo Concept

The GreenLight logo symbolizes illumination and sustainable growth. The design combines a stylized "G" with a light/leaf motif, representing our mission to illuminate the path toward a sustainable future.

---

## Logo Variants

### Primary Logo
- Full color logo for standard use
- File: `assets/logos/greenlight-primary.svg`

### Reversed Logo
- White version for dark backgrounds
- File: `assets/logos/greenlight-white.svg`

### Monochrome Logo
- Single color (black) for limited color applications
- File: `assets/logos/greenlight-mono.svg`

### Icon Only
- Standalone mark without wordmark
- File: `assets/logos/greenlight-icon.svg`

## Clear Space Requirements

```
    ┌─────────────────────────────────────┐
    │                                     │
    │     ┌───────────────────────┐       │
    │     │                       │       │
    │  X  │     GREENLIGHT        │   X   │
    │     │                       │       │
    │     └───────────────────────┘       │
    │                                     │
    └─────────────────────────────────────┘

    X = Height of the "G" in GreenLight
```

Maintain minimum clear space equal to the cap height of the "G" on all sides.

## Color Usage

### On Light Backgrounds
Use the primary green logo (`#00C853`) on white or light gray backgrounds.

| Background | Logo Color |
|------------|------------|
| White (#FFFFFF) | Green (#00C853) |
| Light Gray (#F5F5F5) | Green (#00C853) |
| Mint (#B9F6CA) | Forest (#1B5E20) |

### On Dark Backgrounds
Use the white reversed logo on dark or colored backgrounds.

| Background | Logo Color |
|------------|------------|
| Dark Gray (#212121) | White (#FFFFFF) |
| Black (#000000) | White (#FFFFFF) |
| Forest (#1B5E20) | White (#FFFFFF) |
| Green (#00C853) | White (#FFFFFF) |

## Logo Don'ts

### Never do the following:

1. **Don't stretch or squash**
   - Maintain original proportions at all times

2. **Don't rotate**
   - Logo should always be horizontal

3. **Don't apply effects**
   - No drop shadows
   - No gradients
   - No embossing
   - No outer glow

4. **Don't change colors**
   - Only use approved color combinations
   - Don't add additional colors

5. **Don't add elements**
   - No outlines or borders
   - No additional graphics
   - No taglines attached to logo

6. **Don't use on busy backgrounds**
   - Ensure sufficient contrast
   - Use solid color backgrounds or apply overlay

7. **Don't recreate**
   - Always use official logo files
   - Don't attempt to recreate using fonts

## File Formats

### Vector (for scaling)
- `.svg` - Web and modern applications
- `.ai` - Adobe Illustrator source
- `.eps` - Legacy print applications
- `.pdf` - Universal vector format

### Raster (for specific sizes)
- `.png` - Web with transparency
- `.jpg` - Email and documents (no transparency needed)

### Recommended Exports
| Use Case | Format | Notes |
|----------|--------|-------|
| Website | SVG | Preferred for scalability |
| Email signature | PNG | 200px width, @2x for retina |
| Social profile | PNG | Platform-specific dimensions |
| Print | PDF/EPS | Vector format required |
| Presentation | PNG | High resolution (300dpi) |

## Co-branding

When the GreenLight logo appears alongside partner logos:

1. Maintain equal visual weight
2. Separate logos with a divider line or adequate spacing
3. Never lock logos together
4. GreenLight logo should appear first (left or top position) when primary brand
